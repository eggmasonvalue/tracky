Paused 2026-10-18: current unit shows Err2 on every handle weigh-in; warranty replacement requested.

## Evidence the unit is faulty
- Trunk |Z| at 100 kHz > 20 kHz in every capture (e.g. 37.5 vs 25.9 Ω); limbs are normal. Tissue |Z| cannot rise with frequency.
- Vendor app falls back to feet-only calc every time (8- vs 4-electrode fat differ by > 5 points).
- On a replacement, first check per-segment Z20 ≥ Z100 using a raw capture.

## Architecture review (agreed)
- Keep: Linux owns BLE + canonical SQLite; HTTPS pull sync; Android projection; on-demand MCP.
- Change: derivation runs once on Linux (profile file on the box with height only), sync API emits derived metrics; delete Kotlin DerivationV1 and Android height reads. Supersedes the "no profile data crosses to Linux" decision.
- Gate derived metrics on physical sanity (all 10 channels > 0, Z20 ≥ Z100 per segment) instead of the timing-dependent quality label.
- Version derived records (clientRecordVersion = derivation version) so corrections overwrite Health Connect records.

## Derivation fixes (vendor binary audit, qnscalesdk c9ce0ce x86-64)
- 224/224 coefficients genuine. Water banks mis-transcribed (native has 20/20/21/19 terms; e.g. 0.19986 multiplies Height).
- Native pipeline: T=wF/100; L=w−T; B0=L−A−P; B=clamp(B0,.039w,.051w); δ=(B0−B)/2; A′=A+δ; P′=P+δ; BMR=trunc(370+21.6L). Gate: any Z==0 or >700, or F∉(0,75) → no composition. No 3–75 clamp, no 0.70·LBM fallback, no fixed 4% bone or 73.2% hydration.
- Sex/age affect only visceral/subcutaneous fat, score, body type, body age, not the HC-relevant outputs.
- Spec and native harness: /tmp/qnaudit on the deploy box (volatile; re-derive from the pinned SDK if gone).

## Linux fixes
- Session creation and operation binding are not atomic, so an orphan open session can stall sync forever.
- Scanner has no recovery: exit on adapter/BlueZ loss so systemd restarts it.
- systemd unit wrong (root, paths); need dedicated `tracky` user, StateDirectory, `--db-path`, venv at /opt/tracky.
- MCP needs `--db-path`. Quality classifier: partial-zero bursts accepted; ACK evidence is timing-dependent. Cursor assumes monotonic wall clock.
- `scratch/adhoc_capture.py` deletes its DB on start.

## Android fixes
- Android 17: declare/request ACCESS_LOCAL_NETWORK; bundle the box's self-signed cert (IP SAN) via network_security_config.
- Only weight write permission required; others optional. Add BodyWaterMassRecord. Use local zone offset, not UTC. Store all returned HC record IDs. Fix rationale text.
- Install via adb; open with `am start -n dev.eggmasonvalue.tracky/.MainActivity`.
